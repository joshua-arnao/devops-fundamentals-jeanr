# DevOps Engineer
Es el profesional que ayuda a que el proceso de desarrollar, probar, desplegar y operar software sea más rápido, automatizado, confiable y repetible.

## Qué hace un DevOps Engineer
Sus responsabilidades pueden varia mucho, pero normalmente encontrarás cosas como:

1. **CI/CD**
Automaitza procesos para que los cambios realizados por los desarrolladores puedan pasar por puebas y llegar a los diferentes ambientes.

2. **Infraestructura como Código**
En lugar de crear toda la infraestructura manualmente, busca definirla mediante código.
Esto permite que la infraestructura sea **repetible**, **versionable** y **automatizable**.

3. **Contenedores**

4. **Orquestación**
Cuando una empresa tiene muchos contenedores, puede utilizar herramientas como Kubernetes para administrarlos.

5. **Cloud**
Un DevOps Engineer suele trabajar con al menos una plataforma cloud, por ejemplo:

- Microsoft Azure
- AWS
- Google Cloud

6. **Monitoring / Observability**
Aquí aparecen herramientas como Prometheus, Grafana y las soluciones de observabilidad propias de las plataformas cloud.

7. **Seguridad**
El DevOps Engineer puede colaborar con los equipos de seguridad para integrar estos controles.
