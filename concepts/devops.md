# DEVOPS
Es una cultura de trabajo, se busca hacer **más rápido**, **automatizado**, **colaborativo** y **confiable**  el **ciclo de vida del software**

Dev = Development
Ops = Operations

## SOFTWARE DEVEOPMENT LIFE CICLE (SDLC)
El ciclo de vida del software es el proceso completo de planificar, diseñar, desarrollar, probar, desplegar, operar y mejorar continuamente una aplicación.

### 1. PLANIFICACIÓN
Define **qué problema queremos resolver** y que se va a construir.

> Se considera como: Objetos, Alcance, Tiempo, Recursos, Costos, Riegos

### 2. ANÁLISIS DE REQUISITOS
Se determina exactamente **qué debe hacer el software**

> Aquí aparecen los **requisitos funcionales y no funcionales**

### 3. Diseño
- Se decide **Como se va a construir**
- También se definen tecnologías, arquitectura, seguridad, infraestructura, etc.

### 4. Desarrollo

### 5. Pruebas
Se verifica que el software funcione correctamente.

Pueden existir distintos tipos de pruebas:
- Unitarias
- Integración
- Funcionales
- Seguridad
- Rendimiento
- Aceptación

> En DevOps, muchas de ellas pueden automatizarse dentro de pipelines.

### 6. DESPLIEGUE
El software pasa a un ambiente donde puede ejecutarse. Aquí es donde conceptos como **CI/CD** cobran mucha importancia.

### 7. OPERACIÓN Y MONITOREO
Hay que observar:
- Disponibilidad
- Errores
- Logs
- CPU
- Memoria
- Latencia
- Seguridad
- Experiencia de los usuarios

Si aparece un problema, el equipo debe detectarlo y resolverlo.
