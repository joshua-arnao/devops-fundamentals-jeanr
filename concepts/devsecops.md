# DEVSECOPS
Es una forma de trabajar en la que la seguridad se integra durante todo el ciclo de desarrollo del software, en lugar de dejarla únicamente para el final.

> DevSecOps = Development + Security + Operations

```mkdown
DevOps
Development + Operations
            ↓
Desarrollar → Probar → Desplegar → Operar


DevSecOps
Development + Security + Operations
                 ↓
Desarrollar → Probar → Desplegar → Operar
    ��          ��        ��         ��
      Seguridad en todo el proceso
```

## Shift Left
Shift Left significa llevar actividades como seguridad y pruebas hacia etapas más tempranas del desarrollo.

```mkdown
← TEMPRANO                         TARDE →

Código → Build → Test → Deploy → Producción
  ��        ��      ��
```

> Se busca encontrar los problemas más hacia la izquierda, antes de llegar a producción.
