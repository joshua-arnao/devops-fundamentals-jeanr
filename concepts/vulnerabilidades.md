# VULNERABILIDADES
## Common Vulnerabilities and Exposure - CVE
Identificador público de una vulnerabilidad **concreta** ya conocida. Cátálofo de **hechos**

## Common Vulnerability Scoring System CVSS
Puntuación de **severidad** (típicamente 0.0 - 10.0) para priorizar parches.

## Common Weakness Enumeration - CWE
Categoría del **tipo de fallo en el código o diseño**, on un incidennte específico en tu servior.
